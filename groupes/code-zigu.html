À propos de CODE ZiGU

Histoire : CODE ZiGU (코드지구, « Code Earth ») est un girl group mondial de 7 membres du label JT Corea Entertainment : Mya, Yuna, Daeun, Yerin, Angelina, Natalie et Malia. Les membres viennent de Corée du Sud, des États-Unis, de Mongolie, de France et de Chine. Le groupe a été présenté le 12 octobre 2026, et son single digital de pré-débuts « Zzz » sort le 20 octobre 2026. Sources : K-pop Wiki (Fandom), NamuWiki, Asian Girls Español.
