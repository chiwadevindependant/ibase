IBASE ASIAN POP — CORRECTIF POUR TON ADRESSE GITHUB PAGES
========================================================

Adresse publique : https://ibaseasianpop.github.io/ibase/

Pourquoi l’adresse ne fonctionnait pas
--------------------------------------
Le ZIP précédent contenait CNAME avec « ibaseasianpop.com ». GitHub Pages redirigeait donc vers ce domaine non enregistré. Ce fichier a été supprimé. Les liens des images et catégories ont aussi été corrigés pour le sous-dossier /ibase/.

Comment mettre à jour le site
-----------------------------
1. Télécharge ce ZIP puis décompresse-le.
2. Dans le dépôt GitHub « ibase », remplace les anciens fichiers par TOUT le contenu décompressé (fichiers et dossiers à la racine du dépôt). Supprime aussi l’ancien CNAME s’il reste.
3. Dans GitHub → Settings → Pages, enlève « ibaseasianpop.com » du champ Custom domain s’il est encore indiqué. Choisis « Deploy from a branch », la branche « main » et le dossier « /(root) ».
4. Attends la fin du déploiement GitHub Pages, puis ouvre https://ibaseasianpop.github.io/ibase/ et https://ibaseasianpop.github.io/ibase/groupes/xlov.html.

Google
------
Le sitemap corrigé se trouve ici : https://ibaseasianpop.github.io/ibase/sitemap.xml. Dans Google Search Console, ajoute l’URL de préfixe https://ibaseasianpop.github.io/ibase/, puis soumets l’adresse complète du sitemap. Le fichier robots.txt est livré à https://ibaseasianpop.github.io/ibase/robots.txt. Avec un site de projet GitHub Pages, le fichier robots à la racine du domaine github.io appartient à l’hébergeur et n’est pas contrôlé par ce dépôt.

Le nom, l’icône, les titres et les descriptions aident Google à identifier IBASE Asian Pop, mais Google choisit lui-même le texte et les liens affichés et ne garantit pas de résultat en première position ni l’apparition des catégories comme liens secondaires.

Si tu achètes plus tard ton propre domaine, il faudra le connecter dans les paramètres GitHub Pages et générer à nouveau les balises canonical/sitemap pour ce domaine. Ne réintroduis pas un fichier CNAME avant que le domaine soit réellement enregistré et configuré.
